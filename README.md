# GreenCity Waste Management Collection System

A WordPress-based waste management collection system designed to make household waste collection more organized, trackable, and accountable.

## 🌱 Project Overview


GreenCity connects residents and waste collectors through a structured digital platform.

Residents can register their household information and view their collection details, while collectors can manage pickups and update collection statuses.

The system also allows residents to confirm whether their waste was actually collected.

## ✨ Key Features

* Resident registration and account management
* Resident dashboard
* Collector dashboard
* Household address, state, and LGA information
* Pickup management
* Collection status tracking
* Resident collection confirmation
* Yes/No confirmation when a collection is completed
* Role-based access for residents and collectors
* Responsive web interface

## 🛠️ Technologies Used

* WordPress
* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Elementor
* Ultimate Member
* Forminator
* Advanced Custom Fields (ACF)
* Custom Post Type UI (CPTUI)
* Pantheon

## 🔄 How It Works

1. Residents register their household information.
2. Collection information is managed through the system.
3. Collectors access their dashboard and manage pickups.
4. Collection statuses are updated as pickups progress.
5. Residents confirm whether their waste was collected.
6. The system records the collection outcome.

## 🎯 Project Goal

The goal of GreenCity was to create a simple digital workflow that improves communication between residents and waste collectors while providing better visibility into waste collection activities
